Our resource-safety promise

THE SPACE prioritizes official university and government portals, recognized educational institutions, and first-party documentation from the organizations that maintain the tools. We avoid random download sites, link shorteners, pirated material, unofficial application forms, and links that ask for passwords or one-time codes.

Stay safe: a trusted source can still change or be compromised, and a link being HTTPS does not prove that it is safe. Before registering, paying, downloading software, or applying for an opportunity, confirm the domain and details on the institution's or company's official website. Never pay an individual to secure an internship or job, and never share passwords or OTPs.

We review the sources selected for this page, but cannot guarantee every external page will always be available, current, or risk-free. Report any suspicious or broken link through the feedback section.

Beginner · ECE / IoT

Smart Irrigation Prototype

Goal: Demonstrate watering based on soil moisture.

  • Learn: Sensor readings, thresholds and control logic.
  • Prerequisite: None for the simulated version; basic board setup helps for hardware.
  • Components: Soil-moisture sensor, microcontroller and LED/simulated pump output.
  • First version: Display “dry” or “wet” from sample values, then try a sensor.
  • Improve: Add data logging and adjustable thresholds.
Start with a simulation or LED—not a real pump. Keep electronics dry and use low voltage.
Beginner · Electronics

Automatic Streetlight Model

Goal: Switch an LED model based on ambient brightness.

  • Prerequisite: Basic circuit safety; no coding required if using a simple circuit.
  • Learn: Light sensors and switching thresholds.
  • Components: Light sensor, simple control circuit or microcontroller, LED.
  • First version: Switch one low-voltage LED on/off based on brightness.
  • Improve: Add adjustable sensitivity and a timer mode.
Use a low-voltage LED model; never work on household mains wiring.
Beginner · Sensors

Water-Level Indicator

Goal: Show low, medium and high levels in a small container.

  • Prerequisite: None for a simple LED-and-probe demonstration; controller coding is optional.
  • Learn: Measurement, thresholds and alerts.
  • Components: Suitable low-voltage sensor/probes and LEDs; controller optional.
  • First version: Show one level state before adding multiple indicators.
  • Improve: Add a display or event log.
Keep electronics dry and use suitable low-voltage components.
Intermediate · Sensors & data

Mini Weather Station

Goal: Measure temperature and humidity.

  • Prerequisite: Basic sensor reading and simple programming.
  • Learn: Sensor interfaces, data display and measurement limits.
  • Components: Environmental sensor, controller and optional display.
  • Improve: Graph readings over time and compare readings with a reference.
Simpler first step: read one sensor value in a simulator or serial monitor before adding a display.
Intermediate · Wireless

Wireless Sensor Pair

Goal: Send a sensor reading between two devices.

  • Learn: Communication, data packets and error handling.
  • Components: Compatible boards and wireless modules.
  • Improve: Add timestamps and delivery status.
Intermediate · Software / ECE

Energy-Use Dashboard

Goal: Visualise sample or safely obtained low-voltage measurements.

  • Learn: Data processing and visualisation.
  • Components: Simulated dataset, spreadsheet or web dashboard.
  • Improve: Compare usage over time.
Do not connect a student prototype directly to household mains electricity.
Beginner · Web

Student Resource Finder

Goal: Help students filter trusted learning links by subject and skill.

  • Prerequisite: None for a static first version; JavaScript is optional at first.
  • Learn: HTML, CSS and information design.
  • First version: Make one page with 5 trusted links grouped by topic.
  • Improve: Add JavaScript filters, source dates and broken-link reporting.
You can build the first version without a database, login system or AI.
Intermediate · Data

Study Planner

Goal: Organise subjects, tasks and revision sessions.

  • Learn: UI design, data structures and local storage.
  • Components: Web app and a task list.
  • Improve: Add progress summaries and export.
Advanced · AI / Software

Document Search Assistant

Goal: Search a curated set of course documents and return source-linked results.

  • Learn: Information retrieval, evaluation and privacy.
  • Components: Search index, verified documents and interface.
  • Improve: Add citations and a way to flag incorrect results.
Use only documents you have permission to host and clearly identify the source.
Intermediate · Climate / Data

Local Solar-Potential Explorer

Real-world problem: Help a campus or community compare solar potential using location and historical weather data.

  • Learn: Data analysis, charts, energy concepts and API use.
  • Build: A dashboard that compares solar-radiation data for selected locations and explains its limitations.
  • Improve: Add a transparent estimate of potential generation; label it as an estimate, not a site survey.
Official data: NASA POWER ↗
Intermediate · Geospatial / Environment

Waterbody & Land-Use Change Explorer

Real-world problem: Make it easier to inspect changes in land cover or nearby water resources using official geospatial information.

  • Learn: Mapping, satellite-data interpretation and responsible visualisation.
  • Build: A map-based report using available official layers for a chosen area.
  • Improve: Compare dates where data exists and clearly cite dates, resolution and limitations.
Official starting points: ISRO Bhuvan ↗ · Bhuvan APIs ↗
Advanced · Disaster Resilience / AI

Community Flood-Risk Information Dashboard

Real-world problem: Present public geographic and weather context in a clear dashboard to support preparedness education.

  • Learn: Geospatial data, uncertainty communication and data visualisation.
  • Build: A prototype that maps public information and links to official alerts; do not present it as a certified warning system.
  • Improve: Add accessible map legends, timestamps and links to official emergency updates.
Official context: ISRO Earth-observation applications ↗
Intermediate · Embedded / Accessibility

Indoor Navigation Aid Prototype

Real-world problem: Help visitors locate rooms and facilities in a campus building, with accessibility considered from the start.

  • Learn: Interface design, maps, QR codes and optional low-cost sensors.
  • Build: A phone-friendly floor map with clear routes and accessible labels; test with volunteers and permission.
  • Improve: Add multilingual directions and a way to report blocked routes.
Design for privacy: avoid collecting precise location histories or personal information unless essential and consented.
Intermediate · Sustainability / IoT

Campus Resource-Waste Tracker

Real-world problem: Identify avoidable waste in classroom energy use, water use or recycling through simple, transparent observations.

  • Learn: Sensor logging, dashboards, data quality and sustainability metrics.
  • Build: Start with a manual or simulated dataset, then add safe low-voltage sensors where approved.
  • Improve: Show baseline versus later measurements and explain factors that may affect the comparison.
Use approved data only; never connect student electronics directly to household mains wiring.
Advanced · AI / Trustworthy Software

Source-Cited Engineering Study Assistant

Real-world problem: Help students search trusted notes and official documents while checking where answers came from.

  • Learn: Search, retrieval-augmented generation concepts, evaluation and interface design.
  • Build: Search a small set of permitted documents and display clickable source references with each answer.
  • Improve: Test incorrect-answer cases, add feedback and clearly say when the sources do not answer a question.
Keep documents permissioned, protect user data and never present AI output as verified without checking the cited source.

Choose a level that matches the work

Beginner

First project; guided steps; no prior project experience needed. Use a simulation, LED or simple webpage first.

Intermediate

Requires basic programming/electronics and combining multiple parts, tools or datasets.

Advanced

Requires several skills working together, testing, error handling and careful documentation.

The level describes the minimum version shown here—not every possible extension. Each project should start with the smallest working prototype. If a component or skill is unfamiliar, use the beginner version or complete a prerequisite tutorial first.

Project method

Define

Write the problem and intended user.

Design

Draw a block diagram and choose safe components.

Build

Test one part at a time and keep records.

Document

Show results, limitations and your contribution.

08 / About

A space to learn and build.

THE SPACE is an independent student initiative intended to make useful learning resources easier to discover. Its guiding principle is simple: be curious, be honest about sources, respect the work of others, and use knowledge responsibly.

Transparency matters

This project is not affiliated with or endorsed by VTU, any college, or the companies linked here. External links lead to their respective owners. Resource links, curricula, programmes and eligibility can change. Verify important information at its official source before relying on it.
